# Delivery guides

Use these guides when a workflow is ready to produce something other people
can use. The main Book introduces how delivery fits behind checks; these
examples focus on particular outputs and keep exact action contracts in the
Reference.

## Choose a delivery goal

- [Prepare documentation data for a site](/book/delivery/build-a-documentation-site)
  to validate sources and feed page data into a web application.
- [Deliver project artifacts](/book/deliver-project-artifacts) to connect
  checks, builds, and archive creation.

The built-in actions perform bounded work from declared inputs. They do not
replace application build tools or deploy to an external host unless the action
contract says that they do. Use the
[action reference](/reference/actions) for exact inputs and outputs.
