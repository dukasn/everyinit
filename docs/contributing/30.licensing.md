# Licensing

Everyinit uses different terms for software, documentation, reusable examples,
and original artwork. When contributing material, make sure you have the right
to submit it under the applicable terms. The root
[contribution agreement](https://github.com/dukasn/everyinit/blob/main/CONTRIBUTING.md) covers the Developer
Certificate of Origin sign-off.

| Material | Terms |
| --- | --- |
| Evin, ESH, and other project software | GPL-3.0-only; see [`LICENSE`](https://github.com/dukasn/everyinit/blob/main/LICENSE). |
| Documentation prose | CC BY-SA 4.0; attribution and the same license are required for adaptations. See [`LICENSES/CC-BY-SA-4.0.txt`](https://github.com/dukasn/everyinit/blob/main/LICENSES/CC-BY-SA-4.0.txt). |
| Reusable code examples in documentation | MIT, unless the example identifies another source or license. This applies to code, not diagram syntax. See the [MIT License](https://spdx.org/licenses/MIT.html). |
| Original Everyinit logos, editor icons, and font assets | CC BY 4.0, with attribution and notice of changes. See [`LICENSES/CC-BY-4.0.txt`](https://github.com/dukasn/everyinit/blob/main/LICENSES/CC-BY-4.0.txt). |

Third-party material keeps its own terms. Do not relicense GNU or Rust logos,
or other external material, as project artwork. Preserve required notices and
check [`THIRD_PARTY_NOTICES.md`](https://github.com/dukasn/everyinit/blob/main/THIRD_PARTY_NOTICES.md) when changing
third-party assets.

The artwork license covers only assets Everyinit can license. It does not grant
trademark rights or imply official endorsement. See
[`TRADEMARKS.md`](https://github.com/dukasn/everyinit/blob/main/TRADEMARKS.md) before redistributing or modifying the
project identity.
