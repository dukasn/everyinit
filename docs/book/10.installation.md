# Installation

Bring EVIN into your project with a single command. From there, your build, test, release, and documentation workflows share one visible, deterministic runtime.

## Installing the EVIN CLI

Install the `evin` binary directly from source using Cargo:

```esh
cargo install --path crates/evin
```

Confirm that the CLI is available and check the runtime version:

```tape title="Check runtime" rows=auto cols=64 speed=80ms
type "evin --version"
enter
wait
type "evin --help"
enter
wait
```


> [!NOTE]
> **RFC-1000 Rule §1.1 (CLI Invocation Contract)**
> The `evin` CLI executes commands with strict exit codes, standard I/O streaming, and deterministic path discovery. See [RFC-1000: CLI Reference](/reference/cli-reference).
