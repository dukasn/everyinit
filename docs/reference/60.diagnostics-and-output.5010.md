# Diagnostics and output

> **RFC-5010 · Normative Specification**
> Status: Standard · Category: Diagnostics & Protocol · Conformance: Mandatory

EVIN emits structured, machine-verifiable diagnostics and streaming activity channels.

## 1. Diagnostic Data Model

Each diagnostic emitted by EVIN conforms to the following schema:

```json
{
  "code": "E4501",
  "severity": "error",
  "message": "Circular task dependency detected",
  "source_path": ".evin/workspace.yaml",
  "span": {
    "start_line": 14,
    "start_col": 3,
    "end_line": 14,
    "end_col": 18
  },
  "notes": [
    "Task 'compile' depends on 'lint', which depends on 'compile'."
  ]
}
```

## 2. Severity Levels & Stream Separation

| Severity | Behavior | Output Stream |
| --- | --- | --- |
| `info` | Workflow milestones and phase completion | `stderr` |
| `warning` | Deprecated syntax or non-blocking issues | `stderr` |
| `error` | Blocking failure; halts execution with exit code $> 0$ | `stderr` |
| `debug` | Internal engine state frames (`--debug`) | `stderr` (JSON Lines) |
| **Command Output** | Raw sub-process execution streams | `stdout` / `stderr` |
