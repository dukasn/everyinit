# Contributing

EVIN is built in the open by people who care about how software gets made. Improve the engine, sharpen an action, add a test, or make the explanation clearer for the next project.

- [Development workflow](/contributing/development) - Run the same build, validation, test, and docs workflow the project uses every day.
- [Documentation](/contributing/documentation) - Author Markdown pages that are clear for readers and reliable for the generator.
