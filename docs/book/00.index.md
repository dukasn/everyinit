# The Evin Book

The Evin Book teaches you how to define and run reliable repository workflows:
tasks, dependencies, environments, Git hooks, and delivery routines that stay
close to the code.

## Reading Path

Follow the chapters in sequence to build a practical model from local checks to
automated delivery:

- [Chapter 1: Installation](/book/installation) — Install the CLI, verify your environment, and understand execution guarantees.
- [Chapter 2: First Workspace](/book/first-workspace) — Create your first `.evin/workspace.yaml` and run a declared workflow.
- [Chapter 3: Workspaces & Stages](/book/workspaces) — Master tasks, dependencies, environment matrices, and modular monorepos.
- [Chapter 4: Pipelines & Git Hooks](/book/pipelines-and-hooks) — Automate stage graphs, native Git pre-commit hooks, and watch mode.
- [Chapter 5: Documentation Sites](/book/documentation-site) — Add a validated documentation site as a built-in delivery action.
