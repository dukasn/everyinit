# CLI reference

> **RFC-1000 · Normative Specification**
> Status: Standard · Category: Process Model · Conformance: Mandatory

The `evin` command-line interface provides deterministic process dispatch, exit code propagation, and pipeline orchestration.

## 1. Primary Commands

| Command | Synopsis | Invariants & Guarantees |
| --- | --- | --- |
| `evin init` | `evin init [--all\|--workspace\|--env] [path]` | Creates canonical `.evin/` configuration manifests. |
| `evin sync` | `evin sync` | Rebuilds proxy hooks in `.git/hooks/` to match `.evin/gitrules.yaml`. |
| `evin run` | `evin run <TARGET> [--parallel\|--sequential] [--dry-run]` | Resolves target DAG dependencies and streams task executions. |

## 2. Global Invariants

1. **Exit Code Propagation**: When a pipeline task fails with exit code $N \neq 0$, execution halts (unless `--continue-on-error` is specified) and `evin` terminates with exit code $N$.
2. **Stream Separation**: Standard output (`stdout`) streams task output; pipeline telemetry and diagnostic banners stream to standard error (`stderr`).
3. **Dry-Run Determinism**: `--dry-run` computes the exact DAG execution order without file system side effects or spawning sub-processes.

## 3. Options Reference

| Flag | Long Flag | Behavior |
| --- | --- | --- |
| `-v` | `--verbose` | Emits fine-grained task discovery and timing metrics. |
| | `--dry-run` | Evaluates task resolution graph without execution. |
| | `--debug` | Emits structural JSON debug frames to stderr. |
| `-h` | `--help` | Emits usage synopsis and exits with code 0. |
| `-V` | `--version` | Emits binary version and commit hash. |
