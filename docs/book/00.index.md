# The EVIN Book

Welcome to **The EVIN Book**. This guide teaches you how to design, automate, and scale deterministic workflows across your entire development lifecycle.

## Reading Path

Follow the chapters in sequence to build a complete mental model from local development to automated releases:

- [Chapter 1: Installation](/book/installation) — Install the CLI, verify your environment, and understand execution guarantees.
- [Chapter 2: First Workspace](/book/first-workspace) — Create your first `.evin/workspace.yaml` and run your first stage pipeline.
- [Chapter 3: Workspaces & Stages](/book/workspaces) — Master tasks, dependencies, environment matrices, and modular monorepos.
- [Chapter 4: Pipelines & Git Hooks](/book/pipelines-and-hooks) — Automate stage graphs, native Git pre-commit hooks, and watch mode.
- [Chapter 5: Self-Auditing Documentation Sites](/book/documentation-site) — Ship fast, searchable static docs with binary search and LSP catalog extraction.
