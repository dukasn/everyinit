# Editor integration

Automation deserves the same feedback loop as application code. ESH brings completion, hover documentation, diagnostics, and symbols into the editor through its embedded language server.

## Editor support

```esh
esh lsp
```

## Configure the language server

Register `*.esh` as the ESH language and configure the language server command as `esh lsp`.

```json
{
  "files.associations": { "*.esh": "esh" },
  "generic-lsp.servers": {
    "esh": {
      "command": "esh",
      "args": ["lsp"],
      "languages": ["esh"]
    }
  }
}
```

The same command works for Neovim, Helix, Zed, or any editor with generic LSP support. Point its project root at `.git` or the EVIN workspace configuration.

## Verify the integration

1. Open an `.esh` file.
2. Hover over a built-in such as `json`, `retry`, or `wait_port`.
3. Confirm completions appear while writing a command.
4. Add an unterminated quote and verify that the editor shows a diagnostic.
