# Catalog action

> **RFC-5170 · Implemented interface**
>
> Action identifier: `evin/catalog@v1`

`evin/catalog@v1` compiles Markdown and reStructuredText records into the
versioned JSON catalog consumed by editor and terminal tooling. It has no web
site URL, theme, layout, or preview-server settings.

## Configuration

All fields are optional and unknown fields are rejected.

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `source_dir` | path | `docs` | Source root, relative to the workspace unless absolute. |
| `out` | path | `dist/catalog.json` | Catalog JSON destination, relative to the workspace unless absolute. |
| `include` | string list | `[]` | Source paths, directories, or globs to compile. Empty discovers the full tree. |
| `exclude` | string list | `[]` | Paths and globs excluded from discovery. |
| `extract_frontmatter` | boolean | `true` | Parse Markdown frontmatter before catalog extraction. |
| `reference_prefix` | string | `REF` | Formal reference prefix; ASCII letters and digits only. |

The action uses the shared documentation parser and formal-reference
validation. Catalog source entries use `lsp`, `symbol`, and `keyword` fences or
the equivalent reStructuredText directives. Duplicate names and malformed
entries fail catalog validation before the output is written.

```flow
tasks:
  catalog:
    stage: Docs
    steps:
      - uses: evin/catalog@v1
        with:
          source_dir: docs/reference
          include: ["**/*.md", "**/*.rst"]
          out: dist/catalog.json
```

The task publishes the absolute `output_file` and `symbol_count` (the combined
number of symbols and keywords). `site_url` is not part of this action's
configuration.
