# Evin Shell (ESH)

ESH is a portable shell for project automation. It keeps the useful shape of shell scripting while making expansion, globbing, concurrency, and failure handling explicit. The same script runs through the ESH runtime on Linux, macOS, and Windows.

| Concern | ESH behavior |
| --- | --- |
| Variable expansion | A scalar is always one argument; whitespace is not split implicitly. |
| Globbing | `*` is literal; use the `glob` or `path` built-ins deliberately. |
| Portability | The same runtime runs on Linux, macOS, and Windows. |
| Utilities | Data, filesystem, HTTP, archive, semver, and text tools are built in. |
| Parallel work | `&|` runs independent work concurrently and joins it. |
| Failures | `trap`, status codes, and telemetry identify the failed command and line. |

## Start with a script you can trust

```esh
#!/usr/bin/env esh

set -e
mkdir -p ./dist
cargo test
echo "Checks passed"
```

Run a script with `esh scripts/check.esh`, try a one-liner with `esh -c 'echo hello'`, or inspect a plan without side effects with `esh --dry-run scripts/check.esh`.
