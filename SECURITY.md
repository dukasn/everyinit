# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/dukasn/everyinit/security/advisories/new). Please do not report vulnerabilities in public issues or discussions.

Include the affected component and version, your operating system, steps to reproduce the issue, and its potential impact. The maintainers will review the report and coordinate any fix and public disclosure through the advisory.

Please give the maintainers a reasonable opportunity to investigate and prepare a fix before sharing details publicly. Do not include credentials, personal data, or other secrets in the report unless they are necessary to demonstrate the issue.

## Supported versions

Everyinit is early canary software, and interfaces may change between releases. The maintainers prioritize reports against the latest release and the current `main` branch. Older versions are not guaranteed security fixes; a fix may require upgrading to a newer release.
