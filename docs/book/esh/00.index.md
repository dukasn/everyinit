# Learn ESH

ESH is the script runtime Evin uses for repository `run` steps. You can also
run an `.esh` file directly. ESH has its own syntax, expansion rules, control
flow, and in-process commands.

ESH runs external commands, so those commands must be installed and may have
operating-system-specific behavior. Linux is currently the supported platform
for local development and CI; macOS and Windows are not currently tested in
GitHub Actions. The [ESH Reference](/reference/esh) documents exact language
and runtime behavior.

## Learning path

1. [Write your first ESH script](/book/esh/first-script) and run it directly.
2. [Work with project data](/book/esh/work-with-project-data) using ESH's
   built-in file, text, data, and HTTP commands.
3. [Handle control flow and failures](/book/esh/control-flow-and-failures)
   with conditions, functions, cleanup, and status codes.
4. [Run independent work in parallel](/book/esh/parallel-work) while keeping
   failure reporting visible.
5. Apply the patterns in [automation recipes](/book/esh/automation-recipes)
   and connect an [IDE integration](/book/esh/editor-integration).

Start with [your first script](/book/esh/first-script).
