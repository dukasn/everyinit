# Archive action

> **RFC-5110 · Normative Specification**
> Status: Standard · Category: Built-in Action · Conformance: Mandatory

`evin/archive@v1` turns selected workspace files into a release-ready `tar.gz`. Choose what goes in, what stays out, and how the finished archive is laid out.

| `with` field | Default | Purpose |
| --- | --- | --- |
| `format` | `tar.gz` | Archive format. |
| `path` | required | Destination archive path. |
| `include` | required | Non-empty source path or glob list. |
| `exclude` | empty | Paths to omit. |
| `prefix` | optional | Prefix inside the archive. |
| `layout` | `flat` | `flat` stores basenames; `relative` preserves source paths. |
| `compression_level` | optional | Gzip compression level from 1 to 9. |

```yaml
tasks:
  package:
    stage: Release
    steps:
      - uses: evin/archive@v1
        with:
          path: dist/my-project.tar.gz
          include: [build/**]
          exclude: [build/**/*.map]
          prefix: my-project
          layout: relative
```

Run `evin run package` after the selected files exist. Successful runs expose `path` and `size`; size can be `unknown` in a dry run.
