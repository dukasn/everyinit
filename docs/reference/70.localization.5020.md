# Localization

> **RFC-5020 · Normative Specification**
> Status: Standard · Category: Localization & Internationalization · Conformance: Mandatory

EVIN employs Project Fluent (`.ftl`) resources for deterministic internationalization across all CLI messages, progress indicators, and diagnostics.

## 1. Message Key Invariants

1. **Deterministic Key Names**: Message identifiers follow snake_case prefixes grouping component domains (e.g. `cli_run_started`, `diagnostic_e4501_title`).
2. **Safe Interpolation**: Dynamic parameters passed into Fluent templates are strictly typed and sanitized. Secrets, authentication tokens, and credentials **MUST** be redacted before message formatting.
3. **Fallback Guarantee**: If a key is missing in the user's active locale (`LC_ALL` / `LANG`), the engine gracefully falls back to the canonical English bundle (`en-US`).
