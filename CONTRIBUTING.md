# Contributing

Contributions to Everyinit are welcome. For the development loop, project
layout, and validation tasks, start with the
[contributing guide](docs/contributing/00.index.md).

## Developer Certificate of Origin

By submitting a contribution, you certify that you have the right to submit it
under the applicable project license and agree to the Developer Certificate of
Origin 1.1 in [`DCO.txt`](DCO.txt). Sign off every commit with:

```sh
git commit -s
```

The sign-off adds a `Signed-off-by` line recording that certification; it does
not change the license. Source code uses GPL-3.0-only. Documentation prose,
reusable documentation examples, and original project artwork have separate
terms described in the
[licensing guide](docs/contributing/30.licensing.md).

Use the commit and pull request conventions in `.evin/policy.json`. Keep
changes focused, add or update tests for behavior changes, and update the
relevant user or reference documentation when a public behavior changes.
