# Installation & Quickstart

Install EVIN from the source checkout, then initialize a workspace in the
repository you want to automate.

*Linux · source checkout*

---

## Installation

The supported local development platform is Linux. The repository pins Rust
`1.98.0` in `rust-toolchain.toml`; install Rustup and Git before building from
the source checkout.

```sh
git clone https://github.com/dukasn/everyinit.git
cd everyinit
cargo install --locked --path crates/evin
```

Cargo installs `evin` into its binary directory, normally `$HOME/.cargo/bin`.
Add that directory to `PATH` if needed, then confirm the command is available:

```sh
evin --version
evin --help
```

To run ESH scripts directly as `esh`, install its standalone binary from the
same checkout:

```sh
cargo install --locked --path crates/esh
esh --help
```

Evin workflows can use ESH internally without a separately installed `esh`
command. Install the standalone binary only when you want to invoke scripts
yourself.

## Workspace Configuration

Change to the repository you want to automate and create its workspace file:

```sh
cd path/to/project
evin init
```

This creates `.evin/workspace.flow`. Use `evin init --all` to also create the
environment and Git-rules configuration files. Existing files are skipped,
not overwritten. Run `evin init --help` to see the available options.

The project currently publishes Linux x86_64 release artifacts. The bootstrap
installer endpoint is not available yet, so the source checkout is the
documented installation route. Other operating systems are not currently
supported for local development; see the
[platform policy](/contributing/development#platform-support).
