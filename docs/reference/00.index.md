# Technical Reference

The **Technical Reference** serves as EVIN's normative specifications (the "Rulers"). While [The EVIN Book](/book) provides narrative, pedagogical guides to building workflows, these RFC-style specifications define the strict invariants, grammar, exit codes, and schema rules required for deterministic execution.

## Normative Specifications (RFC Rulers)

| Spec ID | Standard | Scope & Invariants |
| --- | --- | --- |
| **[RFC-1000](/reference/cli-reference)** | CLI Process Model | Subcommands, global options, and stream redirection |
| **[RFC-3000](/reference/esh/language-reference)** | ESH Language Grammar | Lexical analysis, Pratt parsing, and parameter expansions |
| **[RFC-3010](/reference/esh/runtime-reference)** | ESH Built-in Symbol Catalog | Native in-process built-ins and LSP documentation |
| **[RFC-4500](/reference/workspace-configuration)** | Workspace Configuration Schema | Task DAG construction, stage orders, and execution strategies |
| **[RFC-4510](/reference/module-configuration)** | Module Hierarchy & Discovery | Sub-project scoping, discovery rules, and namespacing |
| **[RFC-4520](/reference/environment-configuration)** | Environment Matrix | Variable interpolation, precedence, and preset expansion |
| **[RFC-4530](/reference/git-rules-configuration)** | Git Rules & Hook Protocol | Hook proxy script generation and commit validation |
| **[RFC-5010](/reference/diagnostics-and-output)** | Diagnostics & Telemetry | Structured error codes, diagnostic spans, and rendering |
| **[RFC-5020](/reference/localization)** | Localization Architecture | Message keys, language negotiation, and interpolation |
| **[RFC-5100](/reference/actions/documentation-action)** | Documentation Engine | Compile-time validation, binary search, and LSP generation |
