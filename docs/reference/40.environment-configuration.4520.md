# Environment configuration

> **RFC-4520 · Normative Specification**
> Status: Standard · Category: Environment & Presets · Conformance: Mandatory

`.evin/environment.yaml` defines named execution profiles and reusable task presets across your workspace.

## 1. Schema Definition

```yaml
environments:
  <environment_name>:
    env:
      <KEY>: "<VALUE>"

presets:
  <preset_name>:
    env:
      <KEY>: "<VALUE>"
```

## 2. Variable Resolution Precedence

When resolving environment variables for a task step, values are evaluated in the following order of increasing priority (later sources override earlier ones):

1. **Operating System Host Environment** (Base process environment).
2. **Task Presets** (`presets: [...]` defined in task).
3. **Active Workspace Environment** (`evin run --env <name>`).
4. **Task-Level Environment** (`env: { ... }` declared directly on task).
5. **Step-Level Overrides** (`steps[i].env`).
