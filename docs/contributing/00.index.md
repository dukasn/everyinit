# Contributing

Everyinit welcomes focused changes to the engine, ESH, built-in actions,
editor, website, and documentation. The usual path is to set up the workspace,
make a change with its tests and docs, run the relevant checks, and open a pull
request.

## Choose a guide

- [Development workflow](/contributing/development) — set up the toolchains,
  find the code that owns a behavior, and run focused or workspace checks.
- [Documentation](/contributing/documentation) — write or update the Book,
  reference pages, and site content.
- [VS Code extension development](/contributing/vscode-extension) — build,
  debug, and test the extension.
- [Release infrastructure](/contributing/release-infrastructure) — maintainer
  setup and recovery for automated releases and the artifact mirror.
- [Licensing](/contributing/licensing) — review the terms for code, docs,
  examples, and original project artwork.

Before submitting source changes, read the root
[contribution agreement](https://github.com/dukasn/everyinit/blob/main/CONTRIBUTING.md)
for the DCO sign-off and commit conventions.
