# Debian package action

> Action identifier: `evin/package-deb@v1`

This action builds a `.deb` file from inline metadata and payload mappings.
Each native package format has its own action and strict `with` schema; there
is no format selector or cross-format option set. Reuse scalar metadata through
Flow `values` and templates, while keeping package metadata inline.

The action resolves version and revision from the release artifact referenced
by `release: ${task.release}`. The task must declare that release task in
`needs` and the package's RepositoryPolicy targets must include `deb`.

```flow
values:
  package_name: evin
  package_summary: Evin workflow engine
  package_maintainer: Everyinit contributors
tasks:
  deb:
    needs: [release:state]
    steps:
      - uses: evin/package-deb@v1
        with:
          output_dir: dist
          architecture: x86_64
          release: ${release:state.release}
          package:
            name: ${package_name}
            summary: ${package_summary}
            maintainer: ${package_maintainer}
            homepage: https://everyinit.dev
            payload:
              - source: target/release/evin
                strip_prefix: target/release
                destination: /usr/bin
                mode: 493 # Decimal form of Unix mode 0755
          depends: [libc6]
          description: Workflow engine and portable shell
```

`output_dir` is resolved from the task `cwd` and must remain inside the
workspace. `architecture` accepts `x86_64`, `aarch64`, `x86`, `armv7`,
`riscv64`, `ppc64le`, `s390x`, or `noarch`; the action maps these to Debian's
architecture names (`amd64`, `arm64`, `i386`, `armhf`, `riscv64`, `ppc64el`,
`s390x`, and `all`).

`package` contains required `name`, `summary`, and `maintainer` fields, an
optional `homepage`, and required `payload` mappings. Each mapping has a
`source` path or glob relative to task `cwd`, a non-empty relative
`strip_prefix`, an absolute package `destination`, and an optional integer
`mode` from `0` through `511` (decimal; `493` is `0755`). Matches must be under
`strip_prefix`. Destinations are normalized, collisions fail, and missing
parent directories use mode `0755`. If `mode` is omitted, executable source
files receive `0755`; other files receive `0644`.

DEB-only fields are `description`, `depends`, and optional maintainer script
paths (`scripts.preinst`, `scripts.postinst`, `scripts.prerm`, and
`scripts.postrm`). Script paths are relative to task `cwd` and must resolve
inside the workspace. The output filename is derived from package name,
resolved version and revision, and translated architecture:
`<name>_<version>-<revision>_<architecture>.deb`.

The writer creates deterministic `debian-binary`, `control.tar.gz`, and
`data.tar.gz` members. It does not sign packages or build repository indexes.
Payload paths and modes are normalized, and file timestamps use
`SOURCE_DATE_EPOCH` or the current Git `HEAD` timestamp when it is unset. Evin
writes the package to a same-directory temporary file and atomically replaces
the destination after encoding succeeds.
The `path` and `size` outputs are set on success. In dry-run mode, `size` is
the byte count as a string; it is `0` when payload files resolve and `unknown`
when upstream uncertainty leaves the inputs unresolved.
