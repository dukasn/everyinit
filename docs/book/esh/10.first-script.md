# Your first ESH script

An ESH script is a normal project file interpreted by the ESH runtime. Start by
making the inputs, output location, and failure boundary visible. ESH defines
its own script syntax and built-ins; external commands and operating-system
behavior remain host-dependent.

## Create and run a script

```esh
#!/usr/bin/env esh

set -e
TARGET="${1:-./dist}"

mkdir -p "$TARGET"
cargo build --release
cp ./target/release/app "$TARGET/app"
echo "Wrote $TARGET/app"
```

Save it as `scripts/package.esh`, make it executable when your platform requires it, and run it with an explicit destination:

```esh
esh scripts/package.esh ./artifacts
```

`esh -c 'echo hello'` evaluates one command string. `esh --dry-run scripts/package.esh` parses the file and prints its execution plan without running commands. `esh help json` prints the runtime documentation for a built-in directly in the terminal.

## Pass values deliberately

ESH preserves a scalar expansion as one argument. There is no implicit word splitting or pathname expansion, so a value containing spaces stays intact. Quote values when you want the command to make that boundary obvious.

```esh
DEST="release build files"
mkdir -p "$DEST"

if test -f ./config.yaml; then
  echo "Using $(yaml get config.yaml app.name)"
else
  echo "Missing config.yaml" >&2
  exit 1
fi
```

Use `$NAME` or `${NAME}` to expand a value. Parameter modifiers handle common defaults without separate branching:

| Form | Meaning |
| --- | --- |
| `${PORT:-8080}` | Use `PORT`, or `8080` when it is unset or empty. |
| `${TARGET:=./build}` | Set and use a default target. |
| `${#NAME}` | Length of a scalar value. |
| `$(command)` | Capture command output. |
| `$(( expression ))` | Evaluate signed 64-bit arithmetic. |

## Work with script arguments

The file name is available as `$0`; the arguments that follow it are positional parameters. Functions receive their own positional parameters, so they can package a small operation without relying on global state.

```esh
announce() {
  local NAME="${1:-world}"
  echo "Hello, $NAME"
}

for NAME in "$@"; do
  announce "$NAME"
done
```

Use `return` from a function and `exit` to end the script. See the [Language Reference](/reference/esh/language-reference#commands-status-and-execution) for the exact status rules.
