# Contributing

See the [development workflow](/contributing/development),
[documentation guidance](/contributing/documentation), and
[licensing terms](/contributing/licensing) before making changes.

EVIN is built in the open by people who care about how software gets made. Improve the engine, sharpen an action, add a test, or make the explanation clearer for the next project.

- [Development workflow](/contributing/development) - Run the same build, validation, test, and docs workflow the project uses every day.
- [Release infrastructure setup](/contributing/release-infrastructure) - Configure automated release pull requests and GitHub Releases.
- [Documentation](/contributing/documentation) - Author Markdown pages that are clear for readers and reliable for the generator.
- [VS Code extension development](/contributing/vscode-extension) - Build and run the extension in an Extension Development Host.
