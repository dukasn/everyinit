# Debian package action

> Action identifier: `evin/package-deb@v1`

This action builds a `.deb` file from inline metadata and payload mappings. It
resolves the release revision from the prerequisite action named by
`release: ${task.release}` and publishes `path` and `size` outputs.

```flow
values:
  package_name: evin
  package_summary: Evin workflow engine
  package_maintainer: Everyinit contributors
tasks:
  deb:
    needs: [release:state]
    steps:
      - uses: evin/package-deb@v1
        with:
          output_dir: dist
          architecture: x86_64
          release: ${release:state.release}
          package:
            name: ${package_name}
            summary: ${package_summary}
            maintainer: ${package_maintainer}
            homepage: https://everyinit.dev
            payload:
              - source: target/release/evin
                strip_prefix: target/release
                destination: /usr/bin
                mode: 493
          depends: [libc6]
          description: Workflow engine and portable shell
```

`package` contains shared identity (`name`, `summary`, `maintainer`, optional
`homepage`) and payload mappings. Payload files resolve from task `cwd`; every
match must be beneath `strip_prefix`. Destinations are normalized, collisions
are rejected, and missing parent directories use mode `0755`.

DEB-only fields are `description`, `depends`, and optional maintainer script
paths (`scripts.preinst`, `postinst`, `prerm`, `postrm`). The output filename is
derived from the package name, resolved version and revision, and translated
architecture. `RepositoryPolicy.releases.packages.<name>.targets` must include
`deb`.

The writer creates deterministic `debian-binary`, `control.tar.gz`, and
`data.tar.gz` members. It does not sign packages or build repository indexes.
