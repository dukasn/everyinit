# ESH Reference

ESH is Evin's shell language runtime for project automation. This section
documents the exact language and built-in contracts. For a guided introduction
with examples, start with [Learn ESH](/book/esh).

## Language and runtime contracts

- [Language Reference](/reference/esh/language-reference) defines tokens,
  parsing, expansion, control flow, execution, and error semantics.
- [Runtime Reference](/reference/esh/runtime-reference) lists built-in
  commands, options, inputs, and exit statuses.

ESH owns the meaning of its language constructs and built-ins. External
commands and operating-system interactions still depend on the host. Linux is
currently the supported platform for local development and CI; macOS and
Windows are not currently tested in GitHub Actions.
