# Prepare documentation data for a site

Evin's documentation action parses Markdown and reStructuredText, checks
references and links, and writes a framework-neutral data package. Your web
application owns page rendering, styles, localization controls, version
switchers, and deployment.

## Generate the data package

```flow
stages: [Docs]

tasks:
  docs-data:
    stage: Docs
    description: "Validate docs and generate routes and page data"
    steps:
      - uses: evin/docs@v1
        with:
          source_dir: docs
          out: dist/docs-data
          strict_filenames: true
          i18n:
            default_locale: en
            locales: [en, pt-BR]
```

Run the action before the web app's build:

```sh
evin run docs-data
```

The action writes `manifest.json`, page JSON files, an asset map, and a binary
search index for each version/locale pair under `dist/docs-data`. The manifest
contains the computed routes, available locales and versions, fallback status,
page counterpart mappings, and search artifact metadata. A framework adapter
can consume these records to load pages and expose them through its router.

## Keep the rendering boundary in the application

The page files contain the serialized Evin document AST and metadata. The
application maps AST nodes to its own components and controls the full visual
design. Its router uses manifest routes rather than reconstructing slugs from
source filenames. Locale and version selectors use counterpart records to
keep a reader on the equivalent page when one exists. The `everyinit` runtime
loads and searches the generated binary index, which includes headings, prose,
routes, keywords, references, and result snippets. Vite apps can import
`loadSearchIndex` and `searchDocs` from `virtual:evin/search`.

The Evin action validates source data and emits it. It does not build or serve
the website, choose a theme, or publish the generated application. For exact
configuration and manifest details, see the
[documentation data action reference](/reference/actions/documentation-action).
