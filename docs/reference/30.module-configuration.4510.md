# Module configuration

> **RFC-4510 · Normative Specification**
> Status: Standard · Category: Scoping & Discovery · Conformance: Mandatory

An `.evin/module.yaml` file defines a modular sub-project within a monorepo workspace. Module tasks are namespaced and executed relative to the module root.

## 1. Schema & Discovery

```yaml
module:
  name: <module_name>
  version: "<semver>"

values:
  <key>: "<value>"

tasks:
  <task_name>:
    stage: <StageName>
    description: "Task description"
    steps:
      - run: "<command>"
```

## 2. Invariants & Rules

1. **Discovery Invariant**: A module is recognized by EVIN if and only if its directory path is listed under `workspace.modules` in the root `.evin/workspace.yaml`.
2. **Namespace Format**: A task named `build` defined in a module with `name: api` is invoked globally as `evin run api:build`.
3. **Execution Context**: When running a module task, the working directory (`cwd`) is automatically set to the module's parent directory unless explicitly overridden.
